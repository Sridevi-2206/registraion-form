# Registration Form

A responsive HTML, CSS, and JavaScript registration form with live password strength feedback.

## Features

- Full name, email, phone, password, and confirmation fields.
- Live password strength meter.
- Password requirement checklist.
- Client-side form validation.
- Responsive design for mobile and desktop.

## Run locally

Open `index.html` in a web browser.

## Important

This is a frontend demonstration. For production registration, connect the form to a secure backend, validate data on the server, hash passwords, and use HTTPS.
